# e-plantShopping - Paradise Nursery

Welcome to **e-plantShopping**, a responsive front-end single-page application built using React and Redux Toolkit. This project serves as the final capstone for the IBM Front-End Developer Program.

## 🌿 Application Overview

Paradise Nursery is an intuitive online store catering to indoor plant enthusiasts. The application allows users to seamlessly move between exploring inventory, reading about our mission, and managing a real-time shopping cart.

### Key Features

- **Dynamic Navigation:** Header navbar elements dynamically track total checkout quantities without requiring explicit page refreshes.
- **Organized Categorization:** Plants are grouped into distinct categories like Air Purifying, Aromatic, and Low Maintenance variants.
- **State Operations:** Button components instantly disable upon item additions to safeguard purchase limits.
- **Granular Cart Modifiers:** Supports complete product removal alongside item incrementation or decrementation directly from the Cart summary sheet.

## 🛠️ Technology Stack

- **Framework:** React (Vite-based Build Architecture)
- **Global State Architecture:** Redux Toolkit (@reduxjs/toolkit & react-redux)
- **Design Styles:** Standard native CSS flexbox systems
- **Deployment System:** GitHub Pages Hosting# coding-project-template
